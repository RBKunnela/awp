# Glossary — AWP doctrine

- **AWP (Agent Witness Protocol)** — open protocol + tools to offline-verify portable receipts of agent acts (ch02).
- **agent-witness-protocol** — npm package name for the open verifier (ch02).
- **Anchor** — optional time binding on a receipt (ch04).
- **Chefe 1057** — packaging lock: AWP open / PayBot private (ch01).
- **Honesty boundary** — what PASS does and does not prove (ch02).
- **Issuer** — system that creates the receipt body (witness/platform) (ch02).
- **PayBot / PayBotFin** — product plane; can issue/host witness; not the same as AWP npm alone (ch01, ch03).
- **paybot-mcp** — MCP tools for agent payment/authorize flows (ch03).
- **paybot-sdk** — code SDK for same family flows (ch03).
- **Profile** — receipt class: pay, doc, principal, composite (ch02).
- **Receipt body** — the portable file (e.g. receipt.json) required for verify (ch02).
- **WitnessRecord** — structured content inside AWP evidence (ch04).
